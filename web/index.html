The rover in the lab

The rover sends one JSON line per second, for example {"temp":26.3,"umid":53.2,"dist":85,"luz":334}, over the USB cable. The computer it is plugged into relays each line by MQTT (Web button), or you can plug the cable into this computer (USB button). Code is in the firmware/ folder of the repository.

Where on Earth can we train for the Moon and Mars?

Pick a place on the Moon or Mars. We find its twins on Earth with open NASA data, and show where the match holds and where it breaks.

About Illuminat Horizontes

Each Earth site gets a similarity score per dimension (terrain, materials, temperature, illumination, water and ice, dust and wind, habitability, subsurface, landing and mobility). The match is a weighted average, so changing the mission profile changes the ranking. Every site also shows where the analogy breaks.

Data: 17 Earth sites × 16 Moon and Mars targets. Earth values are measured from NASA and Copernicus data (SRTM30, MODIS, NASA POWER, Copernicus DEM); Moon and Mars values come from published NASA mission results. Only one value is still provisional (NDVI for the McMurdo Dry Valleys).

Imagery credits

  • Earth: NASA Blue Marble (NASA Earth Observatory).
  • Earth relief and elevation: NASA SRTM30 (SRTMGL30, LP DAAC), 27 tiles (90°N to 60°S), averaged to 0.25°. Antarctica shows the satellite image.
  • Moon: NASA SVS CGI Moon Kit (LRO LROC color mosaic), with relief from LRO LOLA (LDEM, 16 px/degree).
  • Mars: NASA 3D Resources global color and normal maps (Viking/MGS, NASA/JPL-Caltech, USGS).
  • Scores: NASA POWER (MERRA-2, CERES, GPM), MODIS NDVI, SRTM30 and mission references for each target (dados/essenciais in the repository).
  • Coordinates marked ≈ are approximate. 3D engine: three.js (MIT).
